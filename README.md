# เอดิเตอร์ข้อความ e-Office

เอดิเตอร์จัดหน้าหนังสือราชการภาษาไทย ทำงานในเบราว์เซอร์ล้วน (ไม่มีเซิร์ฟเวอร์ ข้อมูลอยู่ในเครื่องผู้ใช้)

## เปิดใช้งานบนเครื่องอื่น — เลือกวิธีใดวิธีหนึ่ง

**วิธีที่ง่ายที่สุด: ไฟล์เดี่ยว**
คัดลอกไฟล์ `dist/eoffice-editor-single.html` ไฟล์เดียวไปเครื่องปลายทาง แล้วดับเบิลคลิกเปิด (Chrome หรือ Edge)
ไม่ต้องมีไฟล์อื่น ไม่ต้องต่ออินเทอร์เน็ต

**วิธีแบบหลายไฟล์** คัดลอกให้ครบ **ทั้ง 5 ไฟล์** ไว้โฟลเดอร์เดียวกัน

| ไฟล์ | หน้าที่ |
|---|---|
| `eoffice-editor.html` | ตัวแอปหลัก |
| `quill.js`, `quill.snow.css` | ตัวเอดิเตอร์ (Quill 2.0.3) |
| `eoffice-tools.js` | เครื่องมือเสริม (จัดอัตโนมัติ ตรวจคำ AI ฯลฯ) |
| `eoffice-pastetest.js` | ชุดทดสอบการวางใน e-Office |

ถ้าเปิดแล้วค้างที่ "กำลังโหลด" หรือขึ้นข้อความว่าเปิดไม่ได้ แปลว่าไฟล์ขาด:
- ถ้าไฟล์อยู่ใน OneDrive / SharePoint / Teams ให้เลือก “เก็บไว้ในเครื่องนี้เสมอ” ทุกไฟล์
- ถ้าดาวน์โหลดมาจากอีเมลหรือเว็บ ให้คลิกขวาไฟล์ → คุณสมบัติ → ติ๊ก “ปลดบล็อก” (Unblock)

## นำขึ้นเว็บโฮสต์ (Cloudflare Pages, GitHub Pages, Netlify ฯลฯ)

ให้ deploy **โฟลเดอร์ `dist`** — มี `index.html` อยู่ในนั้น จึงเปิดที่อยู่หลัก `/` ได้ทันที
(ถ้าเผลอ deploy ทั้งโฟลเดอร์โปรเจกต์ `index.html` ที่รากจะพาไปหน้า `eoffice-editor.html` ให้เอง แต่จะไม่มีนโยบายความปลอดภัย)

ขั้นตอนละเอียด การจำกัดผู้เข้าใช้ และการตั้งค่าความปลอดภัย ดูที่ **[DEPLOY.md](DEPLOY.md)**

## หลังแก้โค้ด

แก้ไฟล์หลายไฟล์ตามปกติ แล้วสร้างไฟล์เดี่ยวใหม่ด้วย

```
node build-single.mjs
```

(ต้องมี Node.js) จะได้ไฟล์ใหม่ 2 ชื่อ เนื้อหาเหมือนกัน:
- `dist/index.html` — สำหรับ deploy ขึ้นเว็บ
- `dist/eoffice-editor-single.html` — สำหรับส่งไฟล์เดียวให้ผู้ใช้ทางอีเมล/แชร์ไดรฟ์

หากเบราว์เซอร์ยังแสดงของเก่า ให้กด Ctrl+F5

## ความเป็นส่วนตัว

- เนื้อหาเอกสารเก็บในเบราว์เซอร์ (หรือไฟล์ที่ผู้ใช้เลือก) ไม่ส่งไปที่ใด
- ข้อความจะออกนอกเครื่องเฉพาะเมื่อผู้ใช้ติ๊กยืนยันและกดใช้ฟังก์ชัน AI ในแท็บ “ผู้ช่วย AI” / “จัดอัตโนมัติ”
- ร่างที่จำไว้ผูกกับที่อยู่ไฟล์/โดเมน — ย้ายไฟล์ไปที่อื่นแล้วร่างเดิมจะไม่ตามไป
